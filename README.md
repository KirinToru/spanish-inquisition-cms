# Spanish Inquisition CMS

## Overview
A distributed client-server architecture designed for cross-platform environments natively targeting Windows and Linux (with macOS support as a potential future addition).

## Tech Stack
- **Backend**: Java
- **Frontend**: Holy C
- **Database**: PostgreSQL
